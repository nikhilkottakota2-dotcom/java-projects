# Java Projects Repository

This repository contains a collection of Java projects designed to demonstrate core programming concepts, data structures, and problem-solving techniques. Each project is self-contained and can be run independently.

## 📂 Projects Included

### 1. Bank Management System
- Simulates basic banking operations.
- Features include account creation, deposits, withdrawals, and balance inquiry.
- Demonstrates object-oriented programming principles.

### 2. Library Management System
- Models a simple library system.
- Supports adding books, issuing books to students, and tracking availability.
- Highlights the use of classes, collections, and file handling.

### 3. Student Information System
- Manages student records such as name, roll number, and grades.
- Provides functionality to add, update, and display student details.
- Useful for practicing encapsulation and data management.

### 4. Matrix Addition
- Performs addition of two matrices.
- Reinforces concepts of arrays and nested loops.
- Includes input validation for matrix dimensions.

### 5. Jagged Array Example
- Demonstrates the use of jagged arrays in Java.
- Shows how arrays of varying lengths can be managed.
- Useful for understanding dynamic memory allocation in arrays.

## 🛠️ Requirements
- Java Development Kit (JDK) 8 or higher
- Any Java IDE (e.g., IntelliJ IDEA, Eclipse, NetBeans) or command-line setup
